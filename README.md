# Roche 拍卖会 (Roche Auction House)

一款专为 **Roche** 纯前端应用量身定制的高信任全 JS 插件。本插件采用极简的高端 Instagram (Ins) 视觉风格设计，融入了 **AI 动态 NPC 生成**、**大厅多方抬价拉锯战**、**一锤定音博弈决策** 以及 **线下实体白描小说质感谈判** 等深度互动功能，并原生支持挂载宿主的全局世界书（Worldbook）。

## 🌟 功能亮点

- **具象实体物件偏好**：AI 刷新出来的拍卖品名称均具有极强的现实指向性与生活感（例如：“一条旧围巾”、“象棋盘”、“丢失分针的怀表”），杜绝空洞的奇幻词汇。
- **动态 NPC 买家与竞标账本**：系统不仅会引入宿主已有角色，还会通过 AI 自动构想、生成并清洗出全新的 NPC 竞买者（如古画修复师顾清等）。NPC 会在大厅参与出价并被记入“竞拍历史账本”中，支持折叠查看。
- **一锤定音与多轮拉锯战**：用户上架藏品后，大厅买家们会自发地轮流竞价、你起我伏地抬高价格。用户可以自主选择在价格进入瓶颈期时“一锤定音”敲定成交，或者冒险选择“继续竞拍”。
- **白描小说文体谈判（无代答铁律）**：在 VIP 私密后室中，对话完全代入线下实体白描小说的交谈氛围。**AI 具有不抢话铁律，绝对不会代替用户做任何言语、内心戏或肢体动作的描写**。用户的一举一动完全由自己的自由文本控制。
- **关系网主动联动**：用户挂牌商品后，有概率立刻触发主线中有羁绊的 Character 主动在后台找你谈判，或者直接在大厅展开高热度竞争。

## 📥 普通用户一键安装

1. 打开 **Roche** 主应用。
2. 导航至 **设置 (Settings)** -> **插件中心 (Plugins)**。
3. 点击 **导入/安装外部插件**。
4. 复制并粘贴以下 `manifest.json` 安装链接：
   
  https://raw.githubusercontent.com/wenqv4617-art/roche-seller/main/manifest.json
  
  
  (这是指向我自己的仓库)

5.  点击安装，完成安全授权后，即可在桌面或 Dock 栏中找到 “拍卖会” 入口体验。

📂 多文件目录结构

为了使代码具有高维护性并规避单文件庞大卡死的问题，本项目切分为以下结构：

my-roche-plugin/
  ├── manifest.json   # 插件元数据描述文件（宿主安装入口）
  ├── plugin.js       # 启动引导器，管理全局命名空间与异步资源加载
  ├── api.js          # AI 决策中枢，承载 Prompt 构建、世界书挂载、决策研判
  └── ui.js           # 视图渲染引擎，承载 HTML、Ins-Style CSS 与交互绑定

🛠 自部署与二改指南

如果你希望托管自己的代码，或者在本项目基础上进行二次开发，请仔细修改以下文件路径：

第一步：创建 GitHub 仓库

1.  创建你自己的 GitHub 公开仓库。
2.  将这四个项目文件上传至仓库中。

第二步：修改 manifest.json

打开你仓库里的 manifest.json，修改以下两个核心字段：

  - "author": 修改为你的名字或 ID。
  - "entry": 将 URL 中的占位符替换为你自己的 GitHub用户名/仓库名。
  
    https://raw.githubusercontent.com/你的GITHUB用户名/你的仓库名/main/plugin.js?v=1.2.3

第三步：修改 plugin.js 中的拉取源 (关键步骤)

由于本项目采用多文件并行的动态 fetch 挂载机制，主引导器 plugin.js 会通过一个 repoBase 基准路径来下载 api.js 和 ui.js。

  - 打开你的 plugin.js，定位到大约第 25 行：
    // 必须修改：将此处的地址替换为你自己的 GitHub 仓库 Raw 根路径
    const repoBase = "https://raw.githubusercontent.com/您的GITHUB用户名/您的仓库名/main";
  - 将其修改为你自己的 GitHub 真实仓库路径，否则你的插件在运行后依然会去拉取其他仓库的 api.js 和 ui.js，导致你本地修改的代码不生效。

第四步：推送与清除缓存测试

1.  修改完毕后，将所有代码提交并推送（Push）到你的 GitHub 仓库 main 分支。
2.  在 Roche 宿主中，卸载旧版插件。
3.  重新导入你自己的 manifest.json 链接测试：
    https://raw.githubusercontent.com/你的GITHUB用户名/你的仓库名/main/manifest.json?v=1.2.3
    （如果修改不生效，可以通过修改 v=1.2.3 版本后缀参数来强制绕过 CDN 浏览器缓存）

⚙️ 核心架构与关键文件说明

1. plugin.js (Namespace Bootstrapper)

  - 职责：作为主程序，最先由宿主加载。
  - 命名空间：创建并管理全局共享的 window.RocheSellerAuction
    命名空间。所有状态（state）、宿主对象（roche）和挂载容器（container）均在此处初始化。
  - 隔离设计：它不含有任何业务逻辑，从而极大程度规避了沙盒环境执行上下文 this 丢失的报错问题。

2. api.js (AI Prompts & Logic)

  - createNpcAvatar(initials)：将 NPC 头像 SVG 进行 Base64 编码。不含任何 raw 双引号，绝不会提前闭合
    HTML 的 src="..." 属性，彻底解决了渲染卡死乱码的问题。
  - triggerAIRefreshItems()：挂载全局世界书，引导 AI 按照“强指向性生活物件”法则生成商品，若 AI
    服务繁忙或格式错误，自动触发带日志的报错托底机制。
  - getAIReplyForAuction()：密室谈判 AI 接口，应用了“线下白描小说文体”以及“禁止替 User 行动代答”的极严格提示词约束。

3. ui.js (Render & CSS Stylesheet)

  - 三键避让优化：当处于后室密谈时，动态为 .rsa-body 追加 .rsa-body-chat 样式，将底部 70px
    避让宽度缩减至 16px，完美贴近底部且兼顾安卓自带三键导航栏。
  - 自适应自由输入框：支持 <textarea> 在线换行自由撰写，并附带 ScrollHeight 实时自增高效果，极大优化了手机端密谈博弈时的编辑体验。
  - 竞拍历史抽屉：每张大厅商品卡片右上方配有账本图标，点击可展开 Accordion 出价记录，无需高频请求 AI。

⚠️ 常见问题与缓存规避机制

Q1：为什么我修改了 api.js，但重新安装后页面还是执行的旧代码？

  - A：GitHub Raw 的 CDN 具有 5 分钟的绝对强缓存限制。
  - 解决办法：
    1.  修改你的 manifest.json，递增 "version" 字段（如 1.2.3 升至 1.2.4）。
    2.  修改 manifest.json 内部的 entry 后缀参数为相同的版本号（如 plugin.js?v=1.2.4）。
    3.  在宿主中卸载插件。
    4.  重新安装时，在安装链接后面附带该版本参数：.../manifest.json?v=1.2.4。

Q2：私聊时 AI 反映迟钝，或总是弹出“AI 对话被阻断”？

  - A：密室私下谈判和一锤定音判定非常依赖你的宿主 AI 的能力和连接状态。请确认你已在 Roche 宿主设置中正确配置了 AI 模型 API
    并能通畅对话。
